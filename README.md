# 🎂 Chhim Putheara — 24-Year Birthday Celebration & Story

A cinematic, powerful, and interactive 24th birthday story website for **Chhim Putheara**, born **13 November 2002**.

## ✨ Features
- **Grand Entrance Gate**: Enlarged custom portrait, 3D crown, interactive quotes, and "Enter with Maximum Hype".
- **Cinematic Soundtrack & Fireworks**: Realistic fireworks launch & explosion sound effect coupled with warm Happy Birthday music-box & piano soundtrack.
- **Dynamic Year-to-Year Milestone Loop**: Automatically calculates Chapter 24 (2026), Chapter 25 (2027), Chapter 26 (2028), and days lived without needing an external database.
- **Section 13: Year-to-Year Chapter Vault & Time Capsule**: Private client-side (`localStorage`) birthday memory vault with JSON Backup & Restore.
- **Interactive Story Journey**: Timeline milestones, Family, Companions & Friends slider, Love memories, Motion video clips, Lessons, Dreams, and interactive Easter eggs.

## 🚀 How to Run Locally
1. Double-click `START_BIRTHDAY_WEBSITE.bat` (launches in full-screen with instant audio).
2. Or simply open `index.html` in any modern web browser.
